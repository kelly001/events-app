# RU Events Helsinki — Next.js scaffold

This workspace has been converted to a minimal Next.js App Router scaffold (TypeScript + Tailwind).

Quick start:

```bash
npm install
npm run dev
```

Files added:
- `app/layout.tsx` — root layout
- `app/page.tsx` — homepage stub
- `app/globals.css` — Tailwind + theme variables
- `tailwind.config.cjs`, `postcss.config.cjs`, `tsconfig.json`, `next.config.js`
